# Scripts

- `train.py` trains the intent classifier from a labeled CSV and saves the classifier weights after each epoch to the specified checkpoint directory.
- `evaluate.py` predicts an intent label for a single query or evaluates every row in a labeled CSV using a saved checkpoint. Each run clears and recreates the contents of `out/`. Both modes write `out/evaluation_log.csv` with `query`, `gt`, and `predicted` columns; for a single query, `gt` is blank. CSV evaluation also writes the labeled `out/confusion_matrix.svg`.
- `dataloader.py` reads and validates the CSV, tokenizes each query, and returns model inputs and labels. It expects a `query` column and a target column named `target`, `intent`, `label`, `class`, or `target_class`. Labels must be `VIDEO`, `SEGMENT`, `CLIP`, or `FRAME`.
- `modelling.py` defines the classifier model: a Hugging Face text encoder with a linear layer that predicts one of the four intent labels.
- `__pycache__` contains Python-generated bytecode cache files; it is not source code.

Run the commands below from the repository root. The training command uses the available CSV and includes only required arguments:

```bash
python src/scripts/train.py --train_data_path data/video_query_granularity_600.csv --checkpoint_dir checkpoints/exp1
```

Pass exactly one of `--query` or `--test_csv`. The optional `--model_path` defaults to `checkpoints/exp1/epoch_10.pt`.

```bash
python src/scripts/evaluate.py --query "Show me the full video"
```

Evaluate every sample in the test CSV:

```bash
python src/scripts/evaluate.py --test_csv data/video_query_granularity_test.csv
```
